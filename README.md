You are the last lantern-keeper of a drowned observatory. You cannot attack: you carry a curved ward that reflects the dark's bolts back at it. Hold ten waves and the vow is kept. Vanilla ES modules and canvas 2D, no build step, no network, no external assets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
